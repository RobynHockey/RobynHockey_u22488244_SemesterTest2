Question 2 process explained:
- The 3D model of the University of Pretoria campus was exported from QGIS using the Qgis2threejs plugin.
- Loaded into a web application using Three.js

- Implemented functionality to click on any 3D object 
- Attributes such as name, type, and coordinates are displayed in a popup.

- Implemented a sun slider showing daylight hours from 6 AM to 6 PM.
- Moving the slider adjusts the sun’s position in the 3D model and updates shadows cast by the buildings.
- Sun intensity and ambient light adjust based on time of day.

- Added a header bar displaying the title.
- Includes the sun slider and the time label for the sun slider functionality.
